# A3 production notes

Built from detailed syllabus Module **A3 — Input & Output Devices**  
Unit: **CS · How Computers Work** · Chapter **3 of 5** · Easy

## Teaching covered (syllabus)
- Input devices send information in: keyboard, mouse, mic, camera  
- Output devices send information out: screen, speaker, printer  
- Some devices do both (touchscreen)  

## Mentoring flow
Welcome → bridge from A1/A2 → chapter card → say-with-me → closed-box hook → "doors = devices" → input tour (4 devices) → output tour (3 devices) → mic vs speaker trick + "takes / gives" rule → touchscreen & headset (both) → 7-item sorting game (ask → wait → answer) → video call with Nani story → device detective at home → practice check (speaker) → recap → quiz bridge  

## Visual upgrades over A2
- Illustrated, animated devices (typing keys, mouse click, camera flash, speaker waves, printer paper, touch ripple)
- Soft shadow cards, IN (coral) / OUT (sage) / BOTH (violet) colour language
- Crossfade between beats (`"transition": "crossfade"`)

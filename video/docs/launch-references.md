# Launch video references (YC / SaaS)

Studied patterns from:
- [Aside (YC F25) launch principles](https://www.linkedin.com/posts/josef-newton_if-you-have-an-upcoming-product-launch-video-activity-7391225375021805568-cPkW) — problem first, show don’t tell, specificity, hook→story→vision
- [Speedrun: viral launch videos](https://speedrun.substack.com/p/how-to-make-a-viral-launch-video) — ≥50% product walkthrough; “make money” not “pretty videographer”
- [Flowjam demo structure](https://www.flowjam.com/blog/startup-product-demo-video) — hook 0–5s, proof workflow, single CTA
- [Moonb demo beats](https://www.moonb.io/blog/software-demo-script-examples) — hook → problem → product → workflow → proof → CTA

## What we replicate for Mentr Python Intermediate

| Beat | Seconds | Visual language |
|------|---------|-----------------|
| Hook / pain | 0–4 | Dark + code basics → cut to Intermediate gold |
| Product in | 4–9 | Wide LMS Intermediate home (scroll) |
| Workflow montage | 9–32 | Fast multi-crop shots: study, practice, compiler editor, output |
| Proof | 32–40 | Run output + Intermediate syllabus proof |
| CTA | 40–45 | Logo + mentr.in/learnpython |

## Voice

Open-source **Piper** + **en_IN-spicor-medium** (NavGurukul / IISc SPICOR English dataset — human Indian English recordings, AGPL-3.0).
